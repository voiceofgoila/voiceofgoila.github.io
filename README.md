# Voice of Goila

**গৈলা ইউনিয়নের তথ্য, সেবা ও স্থানীয় খবর এক জায়গায়।**

এই ফ্রি, মোবাইল-ফ্রেন্ডলি ওয়েব অ্যাপে ইউনিয়নের প্রয়োজনীয় প্রতিষ্ঠান, জরুরি সেবা, শিক্ষা, স্বাস্থ্য, ব্যবসা, সরকারি সেবা, গুরুত্বপূর্ণ স্থান, নোটিশ ও স্থানীয় খবর সাজানো যাবে।

## তথ্য পরিবর্তন
`index.html` ফাইলের `const data = [` অংশে প্রতিষ্ঠানের:
- `name` = নাম
- `address` = ঠিকানা
- `phone` = ফোন নম্বর
- `map` = Google Maps link
- `desc` = অতিরিক্ত তথ্য

পরিবর্তন করুন।
