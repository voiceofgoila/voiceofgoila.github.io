Creator integration uses the existing Supabase site_settings table with key creator_profile_v1. The supplied V15 ZIP does not contain js/supabase.js or js/admin.js (they are referenced by its HTML); these must be present in the actual deployed website for settings to load/save. Supabase RLS must allow authenticated admins to upsert site_settings and public visitors to select it. The profile photo is embedded by default; changing it requires a public HTTPS image URL. Social links are hidden until saved.
